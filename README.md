# WhatsApp Auto-Responder

An Android application for automated replies and response management on WhatsApp.

## 📱 Features

- **Automated Responses:** Set up automatic replies for incoming WhatsApp messages.
- **Custom Triggers & Rules:** Define message rules and automated response templates.
- **Notification Listener Service:** Listens to incoming chat notifications and responds automatically.

## 📥 Download & Installation

1. Download the APK: [`WhatsApp-Auto-Responder.apk`](WhatsApp-Auto-Responder.apk)
2. On your Android device, allow installation from unknown sources if prompted.
3. Install the APK and grant notification access permissions to enable auto-responding.

## ⚙️ Specifications

- **Package Name:** `com.aistudio.whatsappautoresponder.zkympl`
- **File Size:** ~22 MB
- **Target OS:** Android
